#### ⭐ Flagship: [ZeroLimitAI](https://www.zerolimitai.com/developers?utm_source=github&utm_medium=profile)

One OpenAI-compatible endpoint that routes every request to the best **free** AI model available right now, with automatic failover. $0 inference.

```python

client = OpenAI(base_url="https://www.zerolimitai.com/api/v1", api_key="zlai_...")
client.chat.completions.create(model="auto", messages=[{"role": "user", "content": "Hello"}])
```
